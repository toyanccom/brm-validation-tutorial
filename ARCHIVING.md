# Trusted repository archiving

Version 1.0.1 provides public synthetic data, documented code, preserved aggregate
results, and hashes in GitHub. The independent research archive is not yet
published and no DOI is claimed. A GitHub commit records a specific snapshot but
must not be presented as an existing Zenodo or OSF deposit.

## Package for deposit

Use `BRM_Data_Code_Archive_v1_0_1_2026-10-07.zip`. It contains the public code and
five complete synthetic CSV files, metadata, figures, data dictionary, validation
checks, and the already public empirical aggregate subset. It contains no
original human workbooks, real individual prediction vectors, manuscript drafts,
editor correspondence, or consent forms. Original provenance and licence notices
remain in the package.

## Deposit steps

1. Use the production Zenodo service at https://zenodo.org/ and select New upload.
   The sandbox service is for testing and must not be cited as the research archive.
2. Upload the prepared ZIP and enter the supplied title, version 1.0.1, authors,
   and description from `ZENODO_METADATA.json`. Select the resource type that
   reflects this teaching software and its accompanying synthetic data. Preserve
   existing licence scope and notices; the MIT notice concerns teaching code and
   grants no rights to excluded human records or third-party material.
3. Check the metadata and make the files public. Reserve a DOI if useful, then
   publish the record. A reserved draft DOI alone is not a public accessible deposit.
4. Open the resulting record in a signed-out browser and download the ZIP. Record
   the actual version DOI and the actual published record URL.
5. Add that real persistent link to Availability of Data and Materials, Code
   Availability, Open Practices Statement, and the data/code citation in the
   manuscript references. Update the editor response and cite the actual version.

An existing OSF or institutional repository may be used instead, provided its
published record and files are accessible and its persistent link is verified.
No record is created by this preparation and no account access is implied.

Official instructions: https://help.zenodo.org/docs/deposit/create-new-upload/

## Restricted empirical inputs

The archival ZIP demonstrates the analytical workflow with independently
generated artificial observations. It does not make the underlying human MOT
records public or establish eligibility for a journal's restricted-data exception.
The authors must verify and accurately explain the original consent and
institutional sharing conditions. The journal retains the decision on whether
the documented code and synthetic illustration satisfy its data policy.
